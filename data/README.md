# 📊 Sales Analytics Dashboard

A Sales Analytics Dashboard developed using Python, Pandas, Matplotlib and Streamlit as part of my CodeAlpha Data Analytics Internship.

## 🚀 Project Overview

This project analyzes sales data and presents the results through an interactive web-based dashboard.

The dashboard helps users understand sales performance using KPIs, charts and interactive filters.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
- CSV Dataset
